## 六、推薦配隊

### 1. 光噪核心爆發隊（菲比主 C 赦罪流）
- **陣容**：`菲比（主 C） + 漂泊者·衍射（副 C / 光噪鋪墊） + 守岸人 / 維里奈（輔助 / 增傷）`
- **解析**：衍射主角快速累積光噪層數，完美觸發菲比新光套的 20% 暴擊與衍射增傷；守岸人提供全隊暴擊與全傷害深化，菲比進入赦罪狀態打出巨額強化重擊與大招。

### 2. 衍射 / 光噪輔助隊（菲比副 C 告解流）
- **陣容**：`衍射/光噪主 C（如贊妮 / 今汐） + 菲比（副 C / 告解輔助） + 守岸人 / 維里奈（生存）`
- **解析**：菲比長按 E 進入告解狀態，高頻施加光噪並透過 2 鏈削弱 10% 衍射抗性，延奏提供高達 60% 光噪傷害加深；在純衍射或光噪體系隊伍（如贊妮、今汐）中能提供最頂級的增傷發動機效益。
